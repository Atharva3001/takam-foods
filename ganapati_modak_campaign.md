# Takam Ganapati Modak Collection

The campaign theme is **“Modak boltoय!”**: every flavour speaks as a funny, self-aware Takam mascot. The visual system keeps the same sticker-bomb, thick-black-outline world as the Takam logo, with a handmade steamed Modak silhouette, rounded expressive eyes, tiny arms, and a different flavour signal for each character. Every asset is designed as a text-free, transparent sticker so it can work independently on a Reel cover, Instagram post, Story, or website card.

## Visual Rules

All mascots should remain **warm, handmade, celebratory, and funny**, never corporate or hyper-realistic. The palette uses Takam mint, peach, mascot yellow, ink outlines, and one flavour-specific accent. Use no rendered text inside the images; the character pose must communicate the joke without relying on typography.

## Recommended Social Format

Use each transparent mascot on a vertical 9:16 Reel cover with its real Modak photo as the background, then use the same mascot as the visual anchor in the corresponding website product card. The first spoken Reel line should use the listed hook, followed by a 10–15 second flavour story showing the filling, texture, and serving moment.
